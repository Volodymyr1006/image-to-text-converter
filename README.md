# Image to Text Converter

Веб-додаток на Angular, який розпізнає та витягує текст із зображень за допомогою [API Ninjas — Image to Text](https://api-ninjas.com/api/imagetotext).

## Можливості

- Завантаження зображення через кнопку вибору файлу або перетягуванням (drag & drop).
- Перевірка файлу перед відправкою: лише **JPEG або PNG**, розмір **до 2 МБ**.
- Попередній перегляд завантаженого зображення.
- Розпізнавання тексту через API та показ результату на екрані.
- Кнопка копіювання розпізнаного тексту в буфер обміну.
- Зрозумілі повідомлення про помилки (неправильний формат, завеликий файл, помилка API, текст не знайдено) та індикатор завантаження.

## Запуск

Потрібен Node.js 20.19+, 22.12+ або 24+.

1. Встановити залежності:

   ```bash
   npm install
   ```

2. Отримати безкоштовний API-ключ на [api-ninjas.com](https://api-ninjas.com) (My Account → API Key).

3. Скопіювати файл `src/environments/environment.example.ts` у `src/environments/environment.ts` і вставити свій ключ:

   ```ts
   export const environment = {
     apiNinjasKey: 'ВАШ_КЛЮЧ',
   };
   ```

   Файл `environment.ts` додано в `.gitignore`, тому ключ не потрапляє в репозиторій.

4. Запустити додаток:

   ```bash
   npm start
   ```

   і відкрити <http://localhost:4200>.

## Як протестувати

Після запуску відкрийте <http://localhost:4200> і пройдіть сценарії нижче.

| № | Дія | Очікуваний результат |
| - | --- | -------------------- |
| 1 | Обрати JPEG або PNG з текстом, розміром до 200 КБ | Зʼявляється попередній перегляд, назва файлу та його розмір |
| 2 | Натиснути «Розпізнати текст» | Кнопка показує «Розпізнаємо…», потім під зображенням зʼявляється блок із текстом |
| 3 | Натиснути «Копіювати» і вставити текст у будь-який редактор | Кнопка на 2 секунди змінюється на «Скопійовано ✓», вставлений текст збігається з розпізнаним |
| 4 | Обрати файл іншого формату (GIF, PDF, WebP) | Повідомлення «Непідтримуваний формат…», файл не приймається |
| 5 | Обрати JPEG або PNG, більший за 2 МБ | Повідомлення «Файл завеликий…», файл не приймається |
| 6 | Перетягнути зображення мишкою в область завантаження | Працює так само, як вибір через кнопку |
| 7 | Обрати зображення без тексту і розпізнати | Повідомлення «На цьому зображенні тексту не знайдено» |
| 8 | Натиснути «Очистити» | Зображення, результат і повідомлення зникають |
| 9 | Запустити без ключа (залишити заглушку в `environment.ts`) | Підказка «Не вказано API-ключ…» |

Автоматичні тести перевіряють правила валідації файлу та збирання розпізнаних слів у рядки:

```bash
npm test
```

| `npm test`      | запускає модульні тести (Vitest) |
| `npm run build` | збирає додаток у папку `dist/`  |

## Важливо про ліміти API

Додаток, згідно з умовою завдання, приймає файли до 2 МБ. Проте безкоштовний тариф API Ninjas обробляє зображення лише **до 200 КБ** — для більших файлів API поверне помилку, і додаток покаже її текст. З преміум-ключем обмеження API становить 5 МБ.

## Структура

```
src/
├── app/
│   ├── app.ts / app.html / app.css      — головний компонент (інтерфейс і стан)
│   ├── image-validation.ts              — перевірка формату та розміру файлу
│   └── image-to-text.service.ts         — запит до API та збирання слів у рядки
└── environments/
    ├── environment.example.ts           — шаблон файлу з ключем
    └── environment.ts                   — локальний файл із ключем (не в git)
```

## Технології

Angular 21 (standalone-компонент, signals, новий синтаксис `@if`), HttpClient, Vitest.
